Generated by `bun tools/site/build.ts`; do not edit by hand. Loaded by the site pages. `audio` in `songs.json` / `waves.json` = bucket base URL `https://storage.googleapis.com/gm-procedural/site/`.

| File | Purpose |
|---|---|
| `songs.json` | `{audio, songs[70]}`. Song = `{id, src, title, by, seconds, mix: {tf, dl, tfp, dlp, tfs}, stems[]}`. Stem = `{ch, drums, notes, label, waves[], tf, dl, tfp, dlp, tfs}` (label from bank-0 instrument / kit name, waves from structure regions × played keys). Used by `songs/index.html`, `assets/player.js`. |
| `stats.json` | `{gm, plus, categories[]}`. `gm` (n 495) / `plus` (n 555): `{n, A, B, C, median, fam: {<family>: layer count}}` (A/B/C = score tiers). `categories[]` = `{cat, n, gm, plus}` mean score per category. Used by `assets/home.js`. |
| `waves.json` | `{audio, waves[495]}`. Wave = `{w, cat, ins[], g, p, src, fl[], note: {drums, bank, program, key}}`: `g`/`p` = gm / gm-plus score ×100, `ins` = instruments using it, `src` = source sample name, `fl` = flags, `note` = playable note. Used by `sounds/index.html`. |
