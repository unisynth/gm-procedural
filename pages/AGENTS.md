# pages

Hand-made listening pages from the fitting rounds, kept in git; their audio (`*.wav`, `*.png`, relative links) lives in git-ignored `build/gm/<name>/` and in the bucket (`tools/publish.sh` → `gs://gm-procedural/gm/pages/<name>/`).

| File | Purpose |
|---|---|
| `ab2/index.html` | A/B stream + vibraslap variants (404 drop Q sweep). |
| `ab3/index.html` | A/B water rings (062 before/now/orig). |
| `disagree/index.html` | Waves where gmfit score and hearing model disagree (o/g pairs). |
| `drums/index.html` | GM drum kit, fitting pass 4 (gen vs orig). |
| `hear/index.html` | Named drums through the hearing model (orig/now/passes). |
| `index.html` | Bucket root: links song A/B, all-sounds page and every round page; source credits. |
| `ks/index.html` | Karplus-Strong attacks (o/g pairs). |
| `noise/index.html` | Cymbal loops: noise vs comb variants. |
| `pilot/index.html` | Pilot A/B round 4: 6 waves, orig/gen + sheets. |
