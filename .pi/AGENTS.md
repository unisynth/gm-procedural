# .pi

pi project config: worktree-init hook, dashboard kb config, prompts, skills. One file here covers the whole tree; skills document themselves in their own `SKILL.md`, so no per-subdir `AGENTS.md`.

| File | Purpose |
|---|---|
| `settings.json` | pi project settings. `worktreeInit`: `gate` `test ! -d node_modules \|\| test ! -d target`, `run` script `pnpm install --frozen-lockfile && cargo fetch`. `flows.editFlow` = `false`. |
| `dashboard/` | `knowledge_base.json`: kb source `filesystem` `.`, `indexAgentsFiles` true, `directoryLevelAgents.enabled` true, `doctrine` `{inject: "kb", write: true}` (DOX). `kb/index.db*` = local kb index, git-ignored (`.pi/**/*.db*`), regenerated. |
| `prompts/` | Slash prompts. `plan-change.md` = minimal plan, files, verify step per task, confirm first. `tdd-loop.md` = test first, minimal impl, refactor on green. `opsx-*.md` (apply, archive, bulk-archive, continue, explore, ff, new, onboard, propose, sync, verify) generated by `openspec init --tools pi`; do not hand-edit. |
| `skills/gmfit/` | Project fit skill. `SKILL.md`: analyze → fit → correct → refine workflow for `assets/gm/waves/NNN.json`, score terms/flags, keep only improvements, re-baseline `scores.json`. `measure.py`: `uv run -q --with numpy python .pi/skills/gmfit/measure.py <wave>` after `gmfit render <wave>`; reads `build/gm/NNN/{orig,gen}.wav` + `assets/gm/structure.json` loop; prints orig/gen/OK-OFF + fix per check the score averages away (f0, buzz 2.5–10 kHz, per-band periodicity, loudness sd, cluster width, rumble < 0.7·f0, top octave, tonal share, onsets, glide, pitch movement, attack grid, percussive share, peaks/frame). Thresholds provisional (add-wav-resynthesis D5). |
| `skills/manage-flows/` | pi-flows skill (`SKILL.md`): create/edit flows and agents from the main session; `disable-model-invocation`. Generic, not repo-specific. |
| `skills/openspec-*/` | `SKILL.md` per OpenSpec op (apply-change, archive-change, bulk-archive-change, continue-change, explore, ff-change, new-change, onboard, propose, sync-specs, verify-change). Generated by `openspec init --tools pi`; do not hand-edit. |
