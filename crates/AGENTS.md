# crates

Rust workspace members. `dls` and `gmgen` are `no_std` (consumed by unisynth in 64k as git dependencies); `gmfit` is a host tool. Nightly toolchain (`rust-toolchain.toml`).

| Crate | Purpose |
|---|---|
| `dls/` | no_std zero-copy DLS1/2 reader for OS GM bank (Win `drivers\gm.dls`, macOS `gs_instruments.dls`). `Dls::parse(&[u8])` → `instruments()`/`find(drums,bank,prog)`, `Instrument::regions()`/`region_for(key,vel)`/`articulation()` (`Connection` art1/art2), `wave(i)` via `ptbl` (`Wave::sample` 8u/16s → f32), `sampler(&Region)` = wave + effective `Wsmp` (region overrides wave). Bounds-checked: malformed → `Err`/`None`, never panic. Parses offsets (never WaveSabre's hard-coded 0x44602). `examples/dump.rs` TSV fingerprint for bank diffing. Feature `write` (alloc): `write::Bank{instruments: Vec<Ins{.., regions: Vec<Rgn>}>, waves: Vec<WaveData{rate, wsmp, samples: Vec<i16>}>}`, `Bank::read(&Dls)` (8-bit widened), `write::write(&Bank) -> Vec<u8>` = DLS1 (`colh`/`lins`/`ptbl`/`wvpl`, lart/art1, rgn, 16-bit PCM); empty articulation/name = chunk omitted; read→write→read lossless on Windows gm.dls (`write_tests.rs`). Default build unchanged (core only). See change: add-procedural-gm-bank. Tests: synthetic RIFF builder + real macOS bank (235 ins/495 waves, skipped if absent) + `GM_DLS=<path>` Windows gm.dls test (never commit the file). Stereo pairs (add-gmplus-bank D5): top-level `LIST 'stpr' { pair: u32 (left,right)… }`; `Dls::pairs()` raw, `Dls::partner(left)` = first pair whose waves parse with equal rate/len/loop, else None; `write::Bank::pairs` (empty = no chunk, output unchanged); tests `pairs_round_trip`, `bad_pairs_are_ignored`, `no_pairs_no_chunk`. AUMIDISynth ignores the chunk (probe render bit-identical). |
