# crates/gmgen/src/fam

Model families (design D4). Each `render(ctx, layer, out)` renders one layer into a zeroed buffer of the wave's length; dispatched from `../render.rs`. Families flagged `periodic` in `../schema.rs` render the `sustain` region exactly periodic over the loop (loop-grid partials / one loop tiled). Only basic IEEE ops + `crate::math` (determinism D5).

| File | Purpose |
|---|---|
| `additive.rs` | Harmonic table `harm` (dB, tail slope), stiff-string inharmonicity, unison detune, per-partial decay, odd/even balance, onset tilt, attack pitch scoop, vibrato as phase modulation (loops stay exact; `vib` Fourier-series pitch table overrides `vib_cents`; `vib_phase`), `am_db`/`am_phase` AM locked to vibrato phasor, `am` table (rows of 8: per-harmonic loudness 1×–4× vib rate), `side` table (sidebands per harmonic, exact on loop), `phase_seed` (0 Schroeder, n hashed random phases for untabled harmonics), `spread` (Gaussian cluster ≤ 25 comps per partial in cents sd on loop grid, replaces unison; power preserved). Control rate every `CR`. Frozen sustain via FFT (D9); test `frozen_sustain_fft_matches_direct`. See change: add-procedural-gm-bank 6.2b–6.2f. |
| `drum.rs` | Body oscillator gliding `freq·ratio` → `freq` (`sweep_t`), shape sine → odd-harmonic, ≤ 3 extra membrane modes on same glide, noise beater click, soft-clip `drive`. Attack/whole only. |
| `fm.rs` | 2–4 sine operators (`ops` rows [ratio, amount, index decay s, index sustain 0–1]; carrier amount = dB, modulator = peak index rad), `algo` 0 stack / 1 pairs 1→0, 3→2, feedback on top op, `glide`, `cyc` rows [cents, dB] pitch/loudness cycle at `cyc_hz` from `cyc_phase`. Sustain: one loop tiled, cycle rate / carrier phase / modulator ratios snapped to whole cycles per loop (exact; feedback warm-up loop). See change: add-procedural-gm-bank D4q, 7.6. |
| `formant.rs` | Saw (PolyBLEP) or pulse (`pw`) source + `noise` aspiration + `jitter` + vibrato through ≤ 5 parallel formant band-passes (`formants` [Hz, bw Hz, dB]). `syl` rows [s, dB, cents]: syllables with own envelopes (`syl_a`, `syl_d`, `syl_glide` pitch fall); `breath_db` noise under layer envelope. Sustain per harmonic × `Biquad::response` on loop grid (exact), voiced only. See change: add-procedural-gm-bank D4r, 7.3. |
| `ks.rs` | Extended Karplus-Strong: noise burst `exc` periods, `dyn` one-pole low-pass, `pick` comb (½ = odd only), one-zero `damp`, dispersion `stretch` + bisection-tuned all-pass, `t60` loop gain, `body` ≤ 4 commuted band-passes [Hz, Q, dB], `buzz` bridge contact. Not periodic (loop hands over to additive sustain). Tests: pitch ≤ 2 cents, decay ≤ 10 %, pick ½ removes even, body/buzz stable. See change: add-procedural-gm-bank 7.1. |
| `metal.rs` | TR-808-style metallic noise: ≤ 6 PolyBLEP squares at `base × ratio` (default 205.3/304.4/369.6/522.7/540/800 Hz), optional white noise, band-pass + high-pass, one/two-stage exp envelope (`d` until `split`, then `d2`). Attack/whole only. |
| `mod.rs` | Declares family modules: additive, drum, fm, ks, formant, metal, modal, noise, shaker, subtractive. |
| `modal.rs` | Resonator ≤ 32 modes [Hz, dB, decay, phase], hit train (`period`, `hit_db`, `jitter`) or measured `hits` table [s, dB]; per-hit glide (`glide`, `glide_t`), attack `ha`, band-passed click (`click_hp`…`click_lp`); `trill_hz`/`trill_cents` FM per hit. Hit times round to nearest sample (file rounding); hit train starts at `dly`. Sustain: `hits` ≤ 1 sparse grid tones; > 1 folded hit train (exact). Test `hit_rotators_match_exact` (D9). See change: add-procedural-gm-bank D4l, D4m, 7.2. |
| `noise.rs` | White noise through ≤ 24 `bands` (centre, Q, dB) or flat, then `hp`/`lp`, envelope, optional AM. Sustain: loop-length pattern filtered circularly (2 warm-ups), tiled, `sweep` ignored. Transient: free noise, centres move `sweep` octaves relaxing with `sweep_t`. |
| `shaker.rs` | PhISEM: `events` (Bernoulli at `rate` × env^`follow`), burst `sdecay` into ≤ 3 `res` band-passes [Hz, Q, dB], `gjit`/`fjit`/`chirp`/`chirp_t`; `Event`. Sustain: loop-length event pattern, rings wrapped (exact). See change: add-procedural-gm-bank D4o, 7.5. |
| `subtractive.rs` | 2 band-limited oscillators (saw/pulse/tri harmonic series) × per-harmonic RBJ response (low/high/band-pass; cutoff + `fenv` octaves, `fa`/`fd`), recomputed every `CR`, interpolated. `ph2` offsets osc 2. Sustain: cutoff frozen, loop grid (exact). Tests: cutoff response, filter sweep, loop. See change: add-procedural-gm-bank 7.4. |
