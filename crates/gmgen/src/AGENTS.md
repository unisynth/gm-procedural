# crates/gmgen/src

Generator library. Public API: `build(only: Option<&[u32]>) -> Vec<u8>` = Windows gm.dls layout as DLS (skipped / unparametrised waves silent, same length), `render_wave(i, &Params)`, `bank::{meta, committed, skeleton, wave_count}`. Render order: layers → gain → harmonic correction (`correct`) → `tf` → soft knee. Feature `std` gates `structure`, `params_json`, `pack`; feature `plus` gates `plus`, `tests_plus`. `correct.rs` + `correct/` coexist (module + submodule dir). Spec: `docs/synth/gm-procedural.md`.

| File | Purpose |
|---|---|
| `bank.rs` | Embedded skeleton + committed params → `RIFF 'DLS '`. `Packed` (skeleton/lens/params; `wave_count`/`skeleton`/`meta`/`committed`/`render_wave`/`build`); `GM` static = gm.dls set always (free fns delegate). `seed_of(pairs, i)`: stereo partner uses left wave's seed so pair stays coherent. Seed = wave index (full = partial build = gmfit). See change: add-gmplus-bank D4. |
| `correct.rs` | Per-wave harmonic correction (D4b): dB gains at harmonics 1..C, linear in harmonic number. Loop = exact DFT/per-bin gain/inverse DFT (stays periodic); attack = linear-phase FIR (129…2049 taps, ≥ 4 periods of f0). `taps`, `gain_at`, `apply`. Submodule → `correct/AGENTS.md`. |
| `correct/` | Deterministic FFT → see `correct/AGENTS.md` |
| `fam/` | Model families additive/noise/drum/metal/modal/shaker/fm/formant/ks/subtractive → see `fam/AGENTS.md` |
| `lib.rs` | Crate root, `no_std` unless `std`/test. Module list; re-exports `build`/`render_wave`/`wave_count` from `bank` (default) or `plus` (feature `plus`). Determinism note: basic IEEE ops + `math`. |
| `math.rs` | Deterministic math: `floor`, `fract`, `sin_cycles`, `cos_cycles`, `exp2`, `exp`, `log2`, `db`, `to_db`, `sqrt`, `midi_hz`, `Rng` (`white`), `to_i16`. IEEE + − × ÷ only, ≈ 1e-6 relative. |
| `pack.rs` | Feature `std`. `assets/gm/` → `Packed {skeleton, lens, params, missing}`; `pack(dir)`. Reads `structure.json` + `waves/NNN.json`; name/`wave` mismatch, out-of-bank index, invalid file = error naming file and wave. Missing file recorded absent (tests fail, build does not). Included by `build.rs` via `#[path]`. |
| `params.rs` | `Layer` (`new`, `get`/`try_get`/`set`/`table`), `Params` (`gain_db`, `pitch`, `numbers`, `validate`, `encode`/`decode` LE f32). Budget/range validation. `try_get` See change: add-procedural-gm-bank 6.2c. |
| `params_json.rs` | Feature `std`. `WaveFile {wave, params, placeholder, note}` ⇄ `assets/gm/waves/NNN.json`: `from_json`, `to_json`. Only explicit scalars written; omitted take schema default; width > 1 tables = arrays of rows. `placeholder` set by `gmfit placeholder`. |
| `plus.rs` | Feature `plus`. gmplus set (32 kHz gm skeleton, params fitted to gmplus sf2): `PLUS: Packed` + same free fns as `bank`. Packed by `build.rs` from `assets/gm-plus/`. 495 + 60 partner waves. See change: add-gmplus-bank. |
| `render.rs` | Wave render: `WaveMeta`, `Ctx` (`grid` exact `Phasor` n/den, `hz`, `freeze`, `t`), `env` (env scalar `dly`: silent before; See change: add-procedural-gm-bank 6.2b), `layer_env`, `Phasor`, `Biquad` (`Kind`, `set`, `response`, `run`), `f0`, `render(meta, p, seed)`, `soft_knee` (> 0.9, never full scale). Regions (D3); dispatch to `fam/`. |
| `schema.rs` | Fixed family schema: `Scalar`/`Table`/`Family` (`periodic` flag), `WAVE`, `FAMILIES` (additive, noise, drum, metal, modal, shaker, fm, formant, ks, subtractive), `family`, `scalar`, `Region`. `MAX_LAYERS` 4, `MAX_NUMBERS` 512, `MAX_CORRECTION` 128, `TF_BANDS` 20, `TF_RATIO` 1.315, `TF_TIMES` (9), `ENV_TIMES` (24). Adding scalar with default keeps old files valid; rename/remove breaks. Shared with `build.rs`, gmfit. `MAX_NUMBERS` 512 See change: add-procedural-gm-bank 6.2e. |
| `structure.rs` | Feature `std`. `assets/gm/structure.json` (`FORMAT` `gm-structure/1`) ⇄ `dls::write::Bank`: `to_json`, `from_json`. One instrument / wave per line. json `pairs` (stereo, only when non-empty → gm file byte-identical; range validated). Writer = `gmfit extract`; reader = `build.rs`. See change: add-gmplus-bank D4/D5. |
| `tests.rs` | gm bank tests (feature `std`): all 495 waves present, determinism, partial build = full, sanity + exact loop periodicity, `spread` loops exactly, structure = gm.dls (`GM_DLS`), pack errors (budget, layers, family, sustain periodic, missing), JSON round trip, modal (modes/hits/trill/loop), shaker, fm sidebands, formant, `pairs` round trip. |
| `tests_plus.rs` | Feature `plus`. All waves present (495 + pairs), 32 kHz determinism, sane + exact loops, region map = gm, `plus_sample_budget` ≤ 15 M (14.46 M, 9.4× gm; was ≤ 11.5 M), partner with left params renders identical (`seed_of`). See change: add-gmplus-bank 2.2–2.4, 4.2. |
| `tf.rs` | Time × band correction (D4c): 20 bands (`centre(b)` = 55·RATIO^b) × ≤ 9 rows (`rows_for`). STFT on attack (Hann², N 512, hop N/4), loop untouched, attack fades to 0 dB over last 10 ms before loop. `apply`, `measure` (fit). `apply_env`/`measure_env`/`env_db`: fine envelope `env` (24 points 0–400 ms) after tf; `env_db_end`: one-shot last env point past end sits at end. See change: add-procedural-gm-bank 6.2b, 6.2i. |
