# crates/dls/src

Crate `dls`: `#![no_std]` outside tests; `extern crate alloc` only with feature `write`. Default build unchanged (core only). Tests: synthetic RIFF builder + real macOS bank (235 ins/495 waves, skipped if absent) + `GM_DLS=<path>` Windows gm.dls tests (skipped if unset; never commit the file).

| File | Purpose |
|---|---|
| `lib.rs` | Reader. `Dls::parse` → `instrument_count`/`instruments`/`find`, `wave_count`/`wave` (via `ptbl` offsets into `wvpl`), `sampler(&Region)` = wave + effective `Wsmp` (region overrides wave), `pairs()`/`partner(left)`. Types `Error{NotDls,Truncated,Missing}`, `Instrument{program,bank_msb,bank_lsb,drums,name}` (`regions`, `region_for(key,vel)`, `articulation`), `Region`, `Wsmp`, `Connection` (art1/art2), `Connections`, `Wave` (`sample` 8u/16s → f32 in [-1,1), OOR = 0). Bounds-checked: malformed → `Err`/`None`, never panic. Stereo pairs (add-gmplus-bank D5): top-level `LIST 'stpr' { pair: u32 (left,right)… }`; `pairs()` raw; `partner(left)` = first pair whose waves parse with equal rate/len/loop, else None. AUMIDISynth ignores the chunk (probe render bit-identical). |
| `tests.rs` | Reader tests on a synthetic RIFF builder (`chunk`/`list`/`wsmp`/`art1`/`fmt`/`bank`): `rejects_non_dls`, `missing_sections_are_errors`, `instruments_and_locale`, `regions_and_wsmp_fallback`, `articulation_blocks`, `waves_decode`, `bad_ptbl_offset_is_none_not_panic`. Real-bank `macos_gs_instruments` (235 ins/495 waves; skips if absent), `windows_gm_dls` (`GM_DLS`, 16-bit waves; skips if unset). |
| `write.rs` | Feature `write` (alloc). `Bank{instruments: Vec<Ins{.., articulation, regions: Vec<Rgn>}>, waves: Vec<WaveData{rate, wsmp, samples: Vec<i16>}>, pairs: Vec<(u32,u32)>}`. `Bank::read(&Dls)` (8-bit widened to 16). `write::write(&Bank) -> Vec<u8>` = DLS1 (`colh`/`lins`/`ptbl`/`wvpl`, lart/art1, rgn, mono 16-bit PCM). Empty articulation/name = chunk omitted. `pairs` empty = no `stpr` chunk, output unchanged. Read→write→read lossless on Windows gm.dls. See change: add-procedural-gm-bank. |
| `write_tests.rs` | Feature `write` tests: `synthetic_round_trip`, `empty_articulation_writes_no_lart`, `gm_dls_round_trip` (`GM_DLS`, skips if unset; read→write→parse lossless, 235 ins/495 waves), `pairs_round_trip`, `bad_pairs_are_ignored`, `no_pairs_no_chunk`. |
