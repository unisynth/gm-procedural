# lib.rs

Shared helpers of `gmfit`; declares modules `analyze audio cmaes desc dsp fit fm formant hear ks modal plus plan wavelet priors score shaker subtractive sheet sf2`.

- Set selection: `Set {Gm, Plus}` (`from_name`/`name`, `select_set`/`set`, `--set gm|plus` on every command, default gm), `assets_dir`/`build_dir` per set, `skeleton`/`meta`/`render_wave` read the plus `structure.json` at run time for `plus`. `placeholder(wave, meta)`, `wave_count`, `wave_path`, `out_dir`, `repo_root`. gmfit depends on gmgen `plus`, so it calls `gmgen::bank::*` for the gm set. See change: add-gmplus-bank 2.1–2.4.
- `Orig`: `load` (GM_DLS, plus: `plus::Targets` from GMPLUS_SF2), `dls`, `wave` = gm.dls wave or gmplus target (`gm_wave` always gm.dls), `targets`.
- `CATEGORIES` (16 GM categories by program/8); `users(i)` = instrument names ("drums:<kit> key N" for kits) + category of first user; `voice(i)` maps a stereo partner to its left wave for `users`/`play_speed`.
- `play_speed(i)` → `(key, speed, instrument)`: bank playback speed 2^((key − unity)/12 + fine/1200), drum-kit key first (Standard), else main melodic user (bank 0 first), at unity clamped to the region's key range (kick 1.0, belltree 0.71). `main_user`/`User{ins, region, key, speed, unity, fine}` picks the region on any bank. Listening pages play at it; `render` report.json `play`. See change: add-procedural-gm-bank D4n/D4p.
- `load_wave` (runtime JSON, no rebuild), `evaluate` (score + describe + `hear::listen` → `heard` 5 values; plain score without corrections), `load_scores`/`save_scores`, `set_param` (paths `gain_db`, `pitch`, `<layer>.<scalar>`, `<layer>.<table>.<index>`, `correction.<index>`; tables grow with zeros).
- `tier`: A ≥ 0.85, B ≥ 0.70, else C; defect flags (`buzz clipped loop_click silent nan`) → C. Calibrated on pilot listening 6.2. See change: add-procedural-gm-bank D4l, 7.2.
- Rank: `rank` = score − `CHAR_PENALTY` 0.1 × `CHAR_FLAGS` (`lines transient_off peaks_off`) − `HEAR_PENALTY` 0.5 × `hear_excess` (added+missing over `hear::AUDIBLE`, moddiff over `MOD_AUDIBLE`, 0.1/dB roughness over `ROUGH_AUDIBLE`, 0.5 × ring over `RING_AUDIBLE`); `rank_json` (scores.json row), `rank_of`. `regressions` = waves whose rank drops > 0.005 (`report --check`). `keep_if_better` writes a wave only when rank beats committed (re-evaluates with descriptors; ranks the rounded on-disk version, 5 digits) and records score. See change: add-procedural-gm-bank D4n, D4p.
- `stereo_check(tl,tr,gl,gr,meta)`: left alone vs mid vs mono target (≤ 0.05 → else `stereo_left_off`), loop corr ≥ 0.3 (else `stereo_low_corr`). Test `phase_inverted_pair_is_flagged`. See change: add-gmplus-bank D4, 4.2–4.3.
