# tools/site

Site builder: generated parts of the GitHub Pages site (`site/`). `bun tools/site/build.ts` → `site/data/{songs,waves,stats}.json`, `site/assets/{live.js,spessasynth_processor.min.js}`, `build/site-audio/{gmgen.wasm,banks/gen-gm.dls}` (→ bucket via `tools/publish.sh`). Audio is not copied: gm.dls renders, MIDI and gmplus.sf2 stream from the bucket `https://storage.googleapis.com/gm-procedural/site/`.

| File | Purpose |
|---|---|
| `bank.ts` | `wasmBank(wasmPath, set)` runs gmgen.wasm under bun like `gmgen-worker.js` (begin/step/finish) → DLS bytes; `sha1`. |
| `bank.test.ts` | bun test: wasm gen-gm == native `build/gm/gen.dls` (sha1); skipped without both artifacts. |
| `build.ts` | Entry (`import.meta.main`). `songs()` (`build/site-audio/results*.json` metrics + `build/gm/songs/selection.json` parts → title/by, stem label from bank-0 instrument / kit name, stem waves from structure regions × played keys), `waves()` (gmfit dump index gm + plus: scores/flags/source + `build/site-audio/waves.json` note), `stats()` (A/B/C counts at 0.85/0.7, median, families, per-category means), `assets()` (copies `gmgen.wasm` to `build/site-audio/`; runs it (`wasmBank`) → `build/site-audio/banks/gen-gm.dls`, throws if ≠ `build/gm/gen.dls`; bun-bundles `live.ts` → `site/assets/live.js` with `GMGEN_WASM_HASH` = sha1[:12] + `GEN_GM_SHA1`, copies `spessasynth_processor.min.js`; `icons()`: `site/assets/icon.svg` → `build/site-audio/icon/{icon-16..512.png,favicon.ico,icon.svg}` via rsvg-convert + magick). Needs `cargo build --profile fast -p gmgen-wasm --target wasm32-unknown-unknown`. Exports `BUCKET`. |
| `live.ts` | Browser engine bundled to `site/assets/live.js`. `Live` (SpessaSynth `WorkletSynthesizer` + `Sequencer`; `use(bank)` replaces sound bank id "main"; `load(midi)`; `solo(ch)` via `isMuted`; `note()` bank select + program + noteOn; `stop()`). `bankBytes(bank)`: gen-gm = prebuilt `banks/gen-gm.dls?v=` checked against `GEN_GM_SHA1` (crypto.subtle), mismatch/error → built; gen-plus built in browser by `gmgen-worker.js` + `gmgen.wasm` (`?v=<hash>`), error → prebuilt `banks/gen-plus.dls`; built banks kept in Cache API `gmgen` key `…/built/<name>.dls?v=<GMGEN_WASM_HASH>` (old versions deleted; no Cache API/quota → no caching); gmplus.sf2 from bucket. `built` ms per bank. gm.dls never loaded. `skipToFirstNoteOn = false`. |
| `titles.test.ts` | bun tests: GUS 8.3 names → title + credit, unknown GUS → capitalised fallback; Novak slugs → `Game — Track` (Doom E1M1, QfG III, Descent level, Warcraft II, Sam & Max). |
| `titles.ts` | `songTitle(id, fallback)` → {`title`, `by`}. `GUS` map of 8.3 names → title/credit (from files' meta text); `GAMES` slug prefixes → game names; track slug prettified. |
