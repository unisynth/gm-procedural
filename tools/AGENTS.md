# tools

bun/shell tools. Each `*.test.ts` runs under `bun test`.

| File | Purpose |
|---|---|
| `gm-songs/` | Full-song A/B of procedural GM bank vs Windows gm.dls (change add-procedural-gm-bank). `smf.ts`: `parse` (SMF 0/1 → channel events on frame clock, tempo map, RMID, sysex/meta dropped), `trim` (first note at 0.5 s), `solo`, `eventText`, `parts` (per channel: programs, keys). `dist.ts`: `dist(gen, orig)` → `tf` (mean \|Δ dB\| third-octave × 46 ms frames after gain), `gain`, `bands`. `render` runs `JOBS` songs at once (default 3: each job ≈ 1 GB; never shard ×8, which ran ~120 renders and exhausted RAM). `render.swift`: AUMIDISynth offline renderer `gmrender <bank.dls> <events.txt> <out.wav>` (preloads programs). `dlsname.ts`: `nameWaves` adds wave `INFO/INAM` + rebuilds `ptbl` (AUMIDISynth keys waves by name; unnamed `dls::write` banks play wave 289 everywhere). `run.ts select\|prepare\|render [--shard i/n]\|page`: `prepare` → `build/gm/songs/banks/` named copies + self-check (zeroed wave 150 silences Organ 1); Novak DOS set + 24 GUS songs by coverage → `build/gm/songs/{selection,results}.json`, mix + solo-channel renders through `build/gm/{orig,gen}.dls`, mp3 pairs, `index.html` A/B page + `report.md` (instruments ranked, wave ids, gmfit score). Inputs in git-ignored `build/gm/midi/`. Test: `gm-songs.test.ts`. → `docs/synth/gm-procedural.md` § Full-song A/B. Four-way (add-gmplus-bank): banks o gm.dls / s gmplus.sf2 (`GMPLUS_SF2`, copied to banks/) / g gen-gm / p gen-plus (`build/gm-plus/gen.dls`); `prepare` self-checks every DLS copy + SF2 probe; `render` mp3 `<name>-{orig,sf,gen,plus}.mp3` with one gain per row, metrics top-level g↔o + `plus` p↔s + `sf` s↔o; `waves` encodes `gmfit dump` output to `waves/NNN-*.mp3`; `page` writes index.html (songs, 'plus fitted' coverage from `assets/gm-plus/waves` placeholders) + waves.html (495 sounds, category/fitted filter); shared `PLAYER_JS` (keys 1–4 same position, seek bar, loop). Stereo gen-plus (D7): `dlsname.ts` exports `waveData`, `pairsOf` (top-level `LIST stpr`), `rightPass`; `prepare` writes `banks/plus-R.dls` + determinism self-check; `render` = left of `plus.dls` + right of `plus-R.dls`; `render` skips songs with four-way results unless `--force`. `serve.ts`: `serve(root, port)` static server, `Bun.file` → Range 206 (players seek; `run.ts serve [port]`, default 60941); `serve.test.ts`. `metrics.ts`: WAV read/write, loudness, octave LTAS (copied from 64k `tools/synth-parity`). `run.ts` `SOURCES`: MIDI + bank credits on both pages. |
| `publish.sh` | Uploads site audio to public `gs://gm-procedural` (`GM_BUCKET`): `build/site-audio/{songs,waves,midi}` → `site/…`, `GMPLUS_SF2` + `build/gm*/gen.dls` → `site/banks/{gmplus.sf2,gen-gm.dls,gen-plus.dls}`, `build/site-audio/gmgen.wasm` → `site/gmgen.wasm` (application/wasm), hand-made `pages/<n>` + `build/gm/<n>/` clips → `gm/pages/<n>/`, `pages/index.html` → root. Never uploads gm.dls, logs, json. `--dry-run`. |
| `site/` | Site builder. `build.ts`: `songs()` (`build/site-audio/results*.json` metrics + selection parts → title/by, stem label from bank-0 instrument / kit name, stem waves from structure regions × played keys), `waves()` (gmfit dump index gm + plus scores/flags/source + `build/site-audio/waves.json` note), `stats()`, `assets()` (copies `gmgen.wasm` to `build/site-audio/` for the bucket, bun-bundles `live.ts` → `site/assets/live.js` with `GMGEN_WASM_HASH`, copies `spessasynth_processor.min.js`). `live.ts`: `Live` (SpessaSynth `WorkletSynthesizer` + `Sequencer`, `use(bank)` replaces bank id "main", `load(midi)`, `solo(ch)` via `isMuted`, `note()`), `bankBytes` (gen-gm/gen-plus from `gmgen-worker.js`, fallback prebuilt; gmplus.sf2 from bucket), `built` ms. `titles.ts`: `songTitle(id)`; `titles.test.ts`. |
| `spessa/` | Site audio with the site's own engine (spessasynth_core). `render.ts songs [--only re] [--part i/n]`: per song gm.dls mix + every channel solo (full length, others muted) → `build/site-audio/songs/<id>/{mix,ch<N>}.mp3`, MIDI copy → `midi/<id>.mid`, metrics `tf`/`d_lufs` gen-gm↔gm.dls, `plus` gen-plus↔gmplus, `sf` gmplus↔gm.dls on full mixes and 30 s solo excerpts → `results[.i].json` (resumable); ~1.6 GB per process, at most 2 parts. `render.ts waves`: `waveNotes()` (structure: kit key first, else melodic region at unity key) → gm.dls note 1.6 s + release (`NOTE`) → `waves/NNN.mp3` + `waves.json`. `skipToFirstNoteOn = false` in both offline and browser so times line up. `probe.ts`: one-bank timing/level check. |
