# tools

bun/shell tools. Each `*.test.ts` runs under `bun test`.

| File | Purpose |
|---|---|
| `gm-songs/` | Full-song A/B of procedural GM bank vs Windows gm.dls (change add-procedural-gm-bank). `smf.ts`: `parse` (SMF 0/1 → channel events on frame clock, tempo map, RMID, sysex/meta dropped), `trim` (first note at 0.5 s), `solo`, `eventText`, `parts` (per channel: programs, keys). `dist.ts`: `dist(gen, orig)` → `tf` (mean \|Δ dB\| third-octave × 46 ms frames after gain), `gain`, `bands`. `render.swift`: AUMIDISynth offline renderer `gmrender <bank.dls> <events.txt> <out.wav>` (preloads programs). `dlsname.ts`: `nameWaves` adds wave `INFO/INAM` + rebuilds `ptbl` (AUMIDISynth keys waves by name; unnamed `dls::write` banks play wave 289 everywhere). `run.ts select\|prepare\|render [--shard i/n]\|page`: `prepare` → `build/gm/songs/banks/` named copies + self-check (zeroed wave 150 silences Organ 1); Novak DOS set + 24 GUS songs by coverage → `build/gm/songs/{selection,results}.json`, mix + solo-channel renders through `build/gm/{orig,gen}.dls`, mp3 pairs, `index.html` A/B page + `report.md` (instruments ranked, wave ids, gmfit score). Inputs in git-ignored `build/gm/midi/`. Test: `gm-songs.test.ts`. → `docs/synth/gm-procedural.md` § Full-song A/B. Four-way (add-gmplus-bank): banks o gm.dls / s gmplus.sf2 (`GMPLUS_SF2`, copied to banks/) / g gen-gm / p gen-plus (`build/gm-plus/gen.dls`); `prepare` self-checks every DLS copy + SF2 probe; `render` mp3 `<name>-{orig,sf,gen,plus}.mp3` with one gain per row, metrics top-level g↔o + `plus` p↔s + `sf` s↔o; `waves` encodes `gmfit dump` output to `waves/NNN-*.mp3`; `page` writes index.html (songs, 'plus fitted' coverage from `assets/gm-plus/waves` placeholders) + waves.html (495 sounds, category/fitted filter); shared `PLAYER_JS` (keys 1–4 same position, seek bar, loop). Stereo gen-plus (D7): `dlsname.ts` exports `waveData`, `pairsOf` (top-level `LIST stpr`), `rightPass`; `prepare` writes `banks/plus-R.dls` + determinism self-check; `render` = left of `plus.dls` + right of `plus-R.dls`; `render` skips songs with four-way results unless `--force`. `serve.ts`: `serve(root, port)` static server, `Bun.file` → Range 206 (players seek; `run.ts serve [port]`, default 60941); `serve.test.ts`. `metrics.ts`: WAV read/write, loudness, octave LTAS (copied from 64k `tools/synth-parity`). `run.ts` `SOURCES`: MIDI + bank credits on both pages. |
| `publish.sh` | Uploads listening pages + renders to public `gs://gm-procedural` (`GM_BUCKET`): `build/gm/songs` (html/mp3/png/json, re-runs `page`), `pages/<n>/index.html` + `build/gm/<n>/` clips → `gm/pages/<n>/`, `pages/index.html` → bucket root. Never uploads dls/sf2/MIDI/logs/`gmrender`. `--dry-run`. |
| `site/` | Site data builder. `build.ts`: `songs()` (results*.json four-way only → id, src, title/by, seconds, mix + stems metrics `tf`/`dl`/`tfp`/`dlp`/`tfs`, stem labels cleaned), `waves()` (dump index.json gm + plus → wave, cat, instruments, scores ×100, gmplus source, flags), `stats()` (tiers A/B/C, median, family layer counts, per-category means from `assets/*/scores.json`) → `site/data/{songs,waves,stats}.json`; `AUDIO` bucket base URL. `titles.ts`: `songTitle(id)` (GUS 8.3 names → title/credit table; Novak game prefixes → "Game — Track"). |
