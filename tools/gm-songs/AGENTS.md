# tools/gm-songs

Full-song A/B of the procedural GM bank vs Windows gm.dls (change add-procedural-gm-bank; four-way with gmplus: add-gmplus-bank). Four banks: o gm.dls, s gmplus.sf2, g gen-gm, p gen-plus, all rendered by Apple AUMIDISynth. Output in git-ignored `build/gm/songs/`; MIDI inputs in git-ignored `build/gm/midi/`. Test: `bun test tools/gm-songs`. → `docs/synth/gm-procedural.md` § Full-song A/B.

| File | Purpose |
|---|---|
| `dist.ts` | Time × band distance of two renders. Exports `BANDS` (26 third-octaves 50 Hz–16 kHz), `bandFrames` (46 ms frames, mono, Hann 2048/hop 1024), `dist(gen, orig)` → `Dist` {`tf` mean \|Δ dB\| after global gain, `gain`, `bands` mean Δ per band}. Ignores frames > 45 dB below loudest orig frame, bands > 50 dB below frame peak. |
| `dlsname.ts` | DLS byte surgery for AUMIDISynth (keys waves by `INFO/INAM`; unnamed `dls::write` banks play wave 289 everywhere). `nameWaves` adds `INAM wNNN` per wave + rebuilds `ptbl`. `waveData` = wave `data` payload offsets. `pairsOf` = top-level `LIST stpr` stereo pairs (add-gmplus-bank D5). `rightPass` = copy with each paired left PCM replaced by partner's (D7, same length by pair contract). |
| `gm-songs.test.ts` | bun tests: `smf` (tempo map + running status, `parts`, `solo`, `trim`/`eventText`), `dist` (identical → 0 with gain removed; different timbre far), `nameWaves` (names every wave, cues right, rest unchanged), stereo pairs (`pairsOf`/`rightPass`; bank without pairs unchanged). |
| `metrics.ts` | WAV read/write (`readWav`, `writeWav`, `Audio`), BS.1770-4 `loudness` (LUFS), `octaveLtas`, `onsets`/`onsetFlux`/`alignment`, `compare`/`formatReport` + `DEFAULT_TOL`. Copied from 64k `tools/synth-parity`; also imported by `tools/spessa/render.ts`. |
| `render.swift` | `gmrender <bank.dls> <events.txt> <out.wav> [rate]`: offline AUMIDISynth renderer → 32-bit float stereo WAV, default 44.1 kHz. `events.txt` = `len <frames>` then `frame b0 b1 b2` lines. Preloads every (channel, bank, program) used. Same renderer for all banks so differences come from the bank only. Build `swiftc -O` → `build/gm/songs/gmrender`. |
| `run.ts` | Driver CLI `select\|prepare\|render [--shard i/n]\|waves\|page\|serve [port]`: curated selection (Novak DOS + 24 GUS by coverage), `prepare` named bank copies + self-check, mix + solo renders → mp3 + metrics, A/B pages + `report.md`. `JOBS` default 3 (~1 GB/job). Exports `SOURCES`. → see `run.ts.AGENTS.md` |
| `serve.test.ts` | bun tests: Range request → 206 + exact slice; `/` → `index.html`; path traversal (`..%2f`) → 404. |
| `serve.ts` | `serve(root, port)` static `Bun.serve`; `Bun.file` Response so Range → 206 (players seek and switch banks at same position; a 200 to Range breaks Chrome). 404 outside root. Used by `run.ts serve` (default port 60941). |
| `smf.ts` | SMF 0/1 reader. `parse(data, rate=44100)` → `Song` {`events` {`frame`, `bytes`}, `frames`, `seconds`}: tempo map applied, RMID unwrapped, sysex/meta dropped, SMPTE rejected. `trim` (first note at 0.5 s), `solo(events, ch)` (drops other channels' notes, keeps controllers/programs), `eventText` (renderer input), `parts` → per-channel `Part` {`ch`, `drums`, `notes`, `programs`, `keys`}. |
